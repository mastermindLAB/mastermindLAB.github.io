How the layout works

Grid

Five fixed columns

Hub, connector lanes, input A, input B, outcome. Every row reuses the same x-positions, which is what makes a 15-row poster read as one system instead of fifteen drawings.

Routing

Nested lanes, no crossings

Rows furthest from the hub get the outermost lane and the outermost port, so the dashed paths nest like brackets and never cross each other.

Encoding

Colour marks the result

Inputs stay neutral cards; only the outcome pill carries colour, cycling through a five-hue palette so the eye tracks the right-hand column.

Type

Fit, then wrap

Labels are measured on a canvas before drawing: they shrink a step, then wrap to two lines, so long names like “Great Expectations” never overflow a chip.
